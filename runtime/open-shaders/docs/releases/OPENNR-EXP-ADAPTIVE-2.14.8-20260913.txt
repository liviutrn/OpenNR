OpenNR EXP — Adaptive Crop / UI / Map Handoff Test
====================================================

This file marks the package as an isolated experimental build.

Correction revision: 20260913-B, current-frame crop boundary handoff.
Adaptive decisions use fresh SteamVR GPU/active-submit workload timings.
Missing or repeated timing samples hold quality; paced FPS is not workload.
Crop transitions render the union of the two tiers and animate the current-frame
feather mask. The previous-frame full-display crop blend is disconnected.
NR uses an elapsed-time fade with corrected recursive weights, neighborhood
clamping, invalid-history rejection, and allocation-aware history sampling.
70-percent NR has explicit resolve parameters.
Resource contract rejection holds crop until restart; NR remains adaptive.
This is a safe hold fallback, not proof of successful native feature caching.
Reset diagnostics are emitted at normal log level; budget status every 300 frames.
