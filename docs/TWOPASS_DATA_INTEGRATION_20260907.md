## Interpretation and next decision

Amplified targets may help learn the desired strong appearance, but exaggeration is not evidence that the task is easier. Pixel L1 gradients do not grow in magnitude merely because a residual is larger. Stronger effects can also amplify clipping, artifacts or inconsistent detail. After eventual training, inspect matching held-out views in each mode, report ordinary MAE/temporal error separately, and retain normal-mode benchmarks. A controlled claim that2x data helps1x learning requires a matched no-2x control, not this joint integration run alone.
